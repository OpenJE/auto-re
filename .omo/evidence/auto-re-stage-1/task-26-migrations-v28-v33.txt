## Design decisions

- All tables use CREATE TABLE IF NOT EXISTS — idempotent, no destructive DDL.
- All primary keys are BLOB (UUIDv7 application-supplied), no AUTOINCREMENT.
- JSON payloads stored as TEXT (matching V14..V27 convention).
- No FOREIGN KEY constraints — all references are loose BLOB columns, per Wave 6 additive-only pattern.
- No cascade deletes, no DB-generated ids.
- Indexes use CREATE INDEX IF NOT EXISTS.
- Timestamps are TEXT (ISO 8601 convention).
- V28/V29 declaration/definition artifacts use loose BLOB refs to generated_source_mappings.
- V30 build_attempts.work_item_id is NULLable (some builds may not be associated with a work item).
- V31 build_diagnostics.build_attempt_id is NOT NULL (every diagnostic belongs to a build).
- V32/V33 verification tables use loose BLOB references for cross-table linkage.
