## Design notes

- Integration test uses `#[path = "../src/tests_support.rs"]` to pull in
  `RecordingAutoReClient` without duplicating ~80 lines of infrastructure.
- Fixture JSON uses `{{PLACEHOLDER}}` tokens (e.g. `{{ENTITY_REF_1}}`,
  `{{CALLER_WORK_ITEM}}`, `{{ACCEPTED_HYPOTHESIS}}`) that are substituted at
  runtime with fresh IDs from a per-test `InvestigationBundle`, so fixtures
  stay stable even when the ID generator changes shape.
- Two shared helpers — `run_happy_case` and `run_malformed_case` — factor out
  the bundle/client/importer plumbing so the 14 `#[test]` functions each read
  as a 3-line assertion. Pure LOC: 239 (under the 250-line ceiling).
- Malformed fixtures violate exactly one spec §8.6 invariant each, and the
  validator's error message mentions the violated rule so the test name is a
  self-describing label of the failure mode.
