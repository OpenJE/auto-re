## Design decisions

- All tables use CREATE TABLE IF NOT EXISTS — idempotent, no destructive DDL.
- All primary keys are BLOB (UUIDv7 application-supplied), no AUTOINCREMENT.
- JSON fields stored as TEXT with '{}' defaults (matching V14..V23 convention).
- Foreign keys without ON DELETE CASCADE (per Wave 17 reconciliation constraint).
- Indexes use CREATE INDEX IF NOT EXISTS.
- Timestamps are TEXT (matching V14..V23 ISO 8601 convention).
- generated_source_mappings.declaration_artifact_id and definition_artifact_id are loose BLOB references (no FK constraint to stage0_artifacts — the referenced artifact may be a generated-source itself that hasn't been committed yet).
- repair_attempts.build_attempt_id is a loose BLOB reference (no FK — build_attempts table may not exist yet in Stage 1 schema).
