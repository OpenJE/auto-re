Design notes:
  * CanonicalEntityKey carries (binary_revision_id, address_space,
    entry_address, entity_kind) as the stable identity; the provider-native
    extension (IDA `ea`, `ida_function_row_uuid`) is a sidecar HashMap and
    is excluded from `stable_key()` and `identity_hash()`.
  * `stable_key()` returns `StableEntityKey::ExternalIdentity{
      namespace = "autore.recon.canonical",
      value = canonical_json,
    }` — `BTreeMap`-backed for deterministic ordering.
  * ObservationImporter.import() issues `RegisterEntity` for unseen
    entities and `ImportProviderRunResult` for rematch. Match detection
    goes through `ApplicationQuery::ListEntities` (no direct SQL).
  * ObservationImporter.import_stale_diagnostics() issues
    `BlockWorkItem(reason="ProviderObservedStaleEntity")` + `CreateWorkItems`
    (one Investigation per stale diagnostic). Entities are NEVER deleted.
  * Tests use `RecordingAutoReClient` — in-memory `AutoReClient` that
    records every ApplicationCommand and answers ListEntities from the
    registered set. Proves that every canonical mutation goes through a
    command, no direct SQL is issued.
  * Observation payload parser accepts: JSON array, object with single
    array value (e.g. `{"entities":[..]}`), or single object.
