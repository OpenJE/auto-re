## Bootstrap Protocol (over raw UDS/TCP)
1. Provider → Coordinator: 32-byte secret (auth)
2. Coordinator → Provider: 1-byte status (0x00 OK / 0xFF fail)
3. Provider → Coordinator: u32 BE min_supported + u32 BE max_supported
4. Coordinator checks if version 1 is in [min, max]
5. Coordinator → Provider: 1-byte status (0x00 OK / 0xFF unsupported)
6. Provider → Coordinator: u16 BE length + UTF-8 gRPC server address
7. Coordinator connects to provider's gRPC server via ProviderClient
8. Full Negotiate RPC for capability exchange + package identity verification

## Design Decisions
- Bootstrap protocol is a simple binary protocol over raw UDS/TCP (NOT gRPC).
- gRPC Provider service runs on provider's own TCP server (127.0.0.1:0).
- Secrets NEVER in argv — only via environment variables.
- BootstrapStream enum implements AsyncRead + AsyncWrite for unified UDS/TCP handling.
- Concurrency limits parsed from NegotiateResponse.max_concurrency (JSON map).
- CancellationToken held in ProviderInstanceHandle for coordinated shutdown.
- No separate watchdog task — child lifecycle managed through GracefulShutdownSeq.
