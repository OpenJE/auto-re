Design decisions
----------------
1. Used `reqwest = 0.12` with `rustls-tls` (default-features=false) rather
   than `ureq` — async-first matches the tokio runtime already used by the
   bootstrap binary, and rustls avoids the system OpenSSL dependency.
2. Used `handlebars = 6` over `tinytemplate` — richer error reporting and
   `register_template_string` for runtime fallback.
3. Introduced a `lib.rs` in addition to `main.rs` so that integration tests
   under `tests/` can import the crate's modules directly (main.rs alone
   would not expose a library target).
4. The `Responder` trait returns `BoxFuture<'a, _>` (dyn-compatible)
   instead of `impl Future` so the client can hold `Arc<dyn Responder>`
   and tests can inject a deterministic mock without generics at the
   client site.
5. Plaintext key is resolved lazily inside `submit()` via `env:VAR` lookup;
   `OpenAiClient` never stores the plaintext value, only the reference.
6. Prompt templates load from `$AUTORE_LLM_PROMPT_DIR` or
   `$CARGO_MANIFEST_DIR/prompts` at startup; fallbacks are embedded so the
   provider boots even with no on-disk templates.
7. Schemas are embedded as `serde_json::Value` constants and serialized to
   bytes for the `CapabilityDescriptor` — avoids file-IO at Negotiate time
   and keeps the binary self-contained.
