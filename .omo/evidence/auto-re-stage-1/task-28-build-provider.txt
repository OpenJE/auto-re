## Design Decisions

1. `trait.rs` is named `trait_def.rs` because `trait` is a Rust reserved keyword.
2. Validation methods (`validate_no_metacharacters`, `validate_image_name`) are
   `pub(crate)` so tests can exercise them directly without going through Docker.
3. `BuildDiagnostic`, `DiagnosticSeverity`, `SuggestedWorkKind` derive `Serialize`
   so the provider binary can serialize diagnostics as observation payloads.
4. `CompileUnit` derives both `Serialize` and `Deserialize` for JSON round-tripping
   in the provider's `execute_compile` handler.
5. Container names are derived from blake3 hash of the project root for determinism.
6. The `echo` binary is used as a fake docker binary in the sequence test — it
   succeeds (exit 0) and prints its arguments, proving the command sequence.
7. `docker_binary` is `Option<String>` in the config, defaulting to `"docker"` when None.
