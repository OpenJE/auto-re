## Implementation summary

3-level import boundary:
  Level 1: Always persist raw response as AddEvidence (predicate=llm.raw-response)
  Level 2: Validate parsed JSON against schema + §8.6 invariants
  Level 3: On success → AddHypothesis per claim; on 1st failure → RepairRequested;
           on 2nd+ failure → FailWorkItem + BlockWorkWithReason → InvalidOutput

Validation invariants checked:
  - Schema conformance (jsonschema::validator_for + iter_errors)
  - Entity existence (evidence_references must reference bundle IDs)
  - Confidence in [0.0, 1.0]
  - Type analysis: sizes/offsets within 1..4096
  - Experiment design: only debug.* capability names
  - Parsed result JSON size ≤ 1 MiB

Repair prompt uses embedded Handlebars template with validation errors,
expected schema, and original bundle context.
