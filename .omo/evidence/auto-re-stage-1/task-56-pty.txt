Design decisions:
  - Dialogs/notifications are not rendered as overlays in the current TUI
    (render() only draws panes, tab strip, and project panel). Commands are
    therefore verified through TUI responsiveness (no crash after dispatch)
    and clean terminal restoration, not by matching dialog text.
  - Alt+N key sequences for Stage 1 pane switching were not used because
    `\x1bN` escape sequences were not reliably interpreted as Alt+N by the
    PTY's crossterm input parser within the `script` harness. The tests
    instead verify keybindings from the default Dashboard pane.
  - Each test reuses the existing `prepare_project`, `auto_re_cmd`,
    `wait_for_content` helpers, plus two new shared helpers
    (`spawn_tui_in_pty`, `quit_and_verify_terminal_restore`) to reduce
    duplication across the three new tests.
