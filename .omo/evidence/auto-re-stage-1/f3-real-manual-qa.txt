SECTION 5: KNOWN LIMITATIONS (from notepads)
================================================================================

1. `reconstruct start` registers the binary as an artifact and creates a
   campaign record. The actual IDA analysis + LLM routing requires the
   autore-stage1 coordinator runtime, which is NOT in default-members.
   Build with: `cargo build -p autore-stage1`

2. No `--mock-mode` flag exists on `reconstruct start`. The operator must
   either run with real providers or test the CLI surface only (steps 1-6
   will create the campaign record but the coordinator loop requires
   stage1 runtime).

3. The `samples/` directory does not exist. The operator must supply a
   binary or use any existing file path.

4. Provider instances (IDA, LLM) must be started separately via
   `auto-re provider start --installation-id <ID>` before the coordinator
   can dispatch work.
